# Data source plan

## FFHQ-Wrinkle
Primary academic wrinkle dataset:
- 1,000 manual wrinkle masks
- 50,000 weak wrinkle masks
- derived from FFHQ
- non-commercial / ShareAlike terms apply

Always retain:
- dataset name
- image ID
- annotation type
- split
- license metadata

## Reference population
Do not scrape arbitrary social-media/search images and invent labels.

Use traceable datasets with known provenance. Store:
- dataset/source
- image ID
- license
- age band if known
- validated skin-tone grouping if available
- extracted skin feature vector

## Feature order
1. Wrinkles
2. Pigmentation
3. Texture
4. Pores
5. Redness
